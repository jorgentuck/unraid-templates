# Unraid templates

Docker templates for Unraid.

| Template | Image |
|---|---|
| [pocket-commander.xml](pocket-commander.xml) | `ghcr.io/jorgentuck/pocket-commander`: root file manager server for the Pocket Commander Android app |

**Use:** Unraid → Docker → Template Repositories → add `https://github.com/jorgentuck/unraid-templates`,
save, then Add Container → pick the template. Or copy the XML to
`/boot/config/plugins/dockerMan/templates-user/`.
